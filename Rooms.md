# Rooms Guide

This document provides a complete guide to all available rooms in the server, including room IDs, names, capacities, and how to access them using the `!room` command.

---

## How to Use `!room`

The `!room` command allows you to instantly join a room by specifying its **internal ID**.
Syntax:

```
!room <internal_id>
```
